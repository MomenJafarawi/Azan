# أذان للماك

## ⬇️ التنزيل
- **[Azan-1.2-mac.dmg](https://github.com/MomenJafarawi/Azan/releases/download/v1.2/Azan-1.2-mac.dmg)**: البرنامج مع ملف التثبيت والتعليمات (macOS 14 أو أحدث، Apple Silicon وIntel)

ملف التثبيت موجود بقسم **Releases** (على يمين صفحة المستودع)، مش مع ملفات الكود.

برنامج مواقيت الصلاة والأذان بشريط القوائم، بشكل "ليل فاخر" (كحلي وذهبي، نجوم وهلال وشهاب).

## الميزات
- مواقيت الصلاة لمدينتك تلقائياً، وطريقة الحساب حسب البلد، والتوقيت الصيفي والشتوي لحاله
- أذان بـ ٨ أصوات، وأذان فجر خاص، وإيقاف الأذان من النافذة أو الويدجت
- أذان ذكي: بيوقّف الموسيقى، ووقت الاجتماعات (المايك شغّال) بيطلع تنبيه صامت
- تنبيه صامت بالكلام: "الله أكبر" بصوت الشيخ، وبعدها "حان الآن موعد أذان ..." (مسجّل داخل البرنامج)
- ورد القرآن وخطة الختمة، والأذكار من حصن المسلم مع عداد، وتذكير الجمعة، ووضع رمضان، والتاريخ الهجري
- ويدجت عائم متحرك على سطح المكتب، وويدجت آبل (صغير ومتوسط)
- فحص كل ملفات البرنامج مع كل تشغيل وإصلاح الناقص تلقائياً

## البناء
يحتاج أدوات Xcode للأوامر (Command Line Tools)، بدون Xcode كامل.

```bash
./build.sh        # يبني ويفحص ويثبّت بمجلد التطبيقات
./build.sh dmg    # كمان بيعمل ملف DMG بـ dist/
```
البناء universal (Apple Silicon + Intel)، ويحتاج macOS 14 أو أحدث.

## المصادر
- أصوات الأذان: مستودع Kiwifu/adhan-mp3 (رخصة غير محددة، للاستعمال الشخصي)
- الأذكار: حصن المسلم
- الخط: Amiri (رخصة OFL)
- صفحات السور: api.quran.com

نسخة الويندوز بمستودع `azan-windows` (لازم يكونوا جنب بعض بنفس المجلد للبناء).

تطوير: مؤمن الجعفراوي
